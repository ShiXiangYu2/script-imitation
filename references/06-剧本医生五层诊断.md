# 06 · 剧本医生五层诊断（C 模式专用）

> 完整版见 `vendor/short-drama-script-revision-framework/SKILL.md`（含决策启发式、修改输出格式、AI 七大致命缺陷手册）。本文件是执行路由。

## 元原则：分诊优先（Triage First）

拿到剧本**第一件事不是改，是诊**：通读 → 按五层漏斗逐层标注（只标不改）→ 输出诊断报告 → 用户确认优先级 → 从最致命的开始修。
**上层没通过，下层改也白改**：L1 结构大改时不要在 L4 对话上花一秒。

## 五层漏斗

| 层 | 检查什么 | 通过标准 |
|---|---|---|
| L1 结构 | 三幕分布、付费卡点（15/30/50/70）、冲突升级曲线 | 分布合理+卡点对位+曲线清晰 |
| L2 场景 | 每集铁三角：[0-5s] Hook / [30-45s] Micro-beat / [85-90s] Cliffhanger；30 秒网格节奏 | 铁三角齐全≥⭐⭐、无连续 2 格空白 |
| L3 角色 | OOC 检查（抽第 1/30/60/90 集对比）、声音盲测、功能重复 | 无 OOC+盲测通过+功能不重复 |
| L4 对话 | AI 味标记词、单句功能（≥2 个功能占比>70%）、句长 5~20 字、口语化 | 标记词归零+密度达标 |
| L5 分镜 | 画面可执行性、每集视觉记忆点 | 描述可直接进 AI 生图提示词 |

## 严重度分级

🔴 P0 致命（前 3 集无 Hook/红线/逻辑断裂）→ 不修=废；
🟠 P1 严重（连续 5 集无 Cliffhanger/情绪平原超 3 集）→ 不修=流失；
🟡 P2 中等（对话 AI 味/语气雷同）→ 不修=品质受损；
🟢 P3 微调（金句密度）→ 锦上添花。

## 虐爽对账（修改核心工序）

逐集标情绪标签（🔴虐🟢爽🟡悬念🔵期待⚪温情）→ 每个 🔴 找还款集：3~5 集内必须有 🟢 回报，否则欠账；纯卖惨无推动 = 坏账，删或加回报。同一情绪类型连续 ≤2 集；大虐前必埋伏，大爽后必留钩。

## 修改最小有效剂量

| 问题 | 最小修改 | 过度修改（避免） |
|---|---|---|
| Cliffhanger 弱 | 重写最后 10 秒 | 重写整集 |
| 对话 AI 味 | 逐句替换标记词 | 重写全部对话 |
| 角色OOC | 该场重注入角色约束 | 重写全部戏份 |
| 节奏拖沓 | 删功能最弱的一场 | 重写整个单元 |

**删 > 改 > 加**；**一处改，三处验**（改任何节拍后检查前后 3 集衔接）；不因「觉得可以更好」重写——说不出明确问题就不改。
