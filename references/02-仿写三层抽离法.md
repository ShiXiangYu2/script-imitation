# 02 · 仿写三层抽离法（剥壳留核 · 神似而非形似）

> 融合 `vendor/short-drama-factory/references/mechanism-imitation.md` 与 `vendor/emma-screenwriting-skills/skills/em-adaptation/SKILL.md`。

## 一、三层抽离表（拆解任何对标必走）

| 层级 | 包含要素 | 处置原则 | 工程动作 |
|---|---|---|---|
| **L1 表皮外壳层**（形似区） | 角色名、专有宗门/公司/机构名、标志性道具、金句口头禅、开场第一镜老梗 | ❌ **绝对禁用（零重合）** | 先列《对标原剧外壳禁用词表》10~20 词，正文出现 1 处即回炉（机检 FAIL） |
| **L2 结构骨架层**（过渡区） | 人物功能位拓扑、冲突形态、反转标签序列 | 🔄 **换三留一** | 保留权力张力拓扑，必换行业背景、社会关系、冲突场景（豪门认亲晚宴 → 实验室专利署名发布会） |
| **L3 底层机制层**（神似区） | 情绪契约、信息差方向、筹码兑换算式、15秒换挡节拍、付费墙落位 | ✅ **全额复用** | 还原为公式 `信息差 × 兑换货币 × 施压反将节拍`，在新壳里跑出同一条爽感曲线 |

emma 补充的关键判断：迁移时保留的是**戏剧功能**，不是桥段组合。拆三层时每写一条要问：它提供的是时间线、能力展示还是对手反应？生效条件是什么？只换人名职业保留独特桥段组合 ≠ 新故事。

## 二、四维算式卡（禁止摘抄台词，只抽公式）

1. **信息差算式（谁不知道什么）**：
   - 全知碾压型：观众与主角知道底牌，反派眼瞎往枪口撞（爽在看小丑作死）；
   - 认知错位型：双方各握一个维度，把日常举动脑补成绝世布局（爽在跨服错位）；
   - 隐藏护短型：弱小一方背后站着降维靠山，欺负一寸当场十倍奉还（爽在当场结算）。
2. **筹码兑换算式**：任何高维设定（医术/权势/先知/手艺）每集必须绑定一个**世俗可计价的燃眉之急**（五万块救命钱/学区房资格/破产清算书）。公式：`顶级底牌 → 解决当集世俗死线 → 当场兑现可见收益 + 反派付出可见代价`。
3. **单集换挡算式（15秒四拍）**：`0~15s 立死线 → 15~45s 正面逼压 → 45~85s 亮物证翻转 → 85~110s 结算+新危机钩子`。
4. **单元闭环算式**：第 10~15 集攻守转换（一级墙）、第 20~30 集结清旧单元从残渣引爆新单元（二级墙）。

模板：`templates/算式卡.md`。

## 三、换皮三连（Step 3）

1. **换赛道/职业背景**：古装宅斗 → 现代非遗老字号争产；赘婿龙王 → 隐退首席芯片架构师；
2. **换核心物证载体**：九龙玄铁令 → 国家级绝密专利授权书；
3. **换开局前 3 秒视觉奇观**：严禁照抄原剧第一集第一个动作，必须用新职业的高反差强画面开场。

## 四、独创造血（Step 3.5 · 防撞车）

每单元六档证据阶梯中，**至少 2 档以上**必须是由新职业/新背景推导出的原生桥段；严禁逐场对应原剧场次顺序。

## 五、相似度四问自检（出稿前必查）

1. 遮住新名字，台词句式还能看出原剧影子吗？（是 → 重写台词）
2. 开局前 3 秒冲突道具与原剧同类吗？（是 → 换物理动作与物证）
3. 连续两场戏与原剧 1:1 映射吗？（是 → 打乱，替换为新背景原生事件）
4. 爽感节奏一样快、故事面貌完全是新剧吗？（否 → 回 L2 重换皮）

本方法仅用于合法的结构研究与机制级参考。思想、题材、节拍公式不受版权保护，**具体独创表达受法律保护**。用户粘贴他人成片逐字稿/剧本要求「洗稿/改个名字直接用」时：**必须拒绝逐句换词**，只输出 L2 结构拓扑 + L3 戏剧算式的抽象拆解表，协助换皮原创。
