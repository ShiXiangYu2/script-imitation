# 07 · 版权与合规红线

## 一、版权边界（本工作流的生存底线）

- **不受版权保护**：思想、题材类型、戏剧节拍公式、情绪结构；
- **受法律严格保护**：具体独创表达（台词、桥段组合、专有名词）。

### 触发拒绝的场景

用户粘贴他人成片逐字稿/剧本原文，要求「帮我洗稿」「改个名字直接用」「换个说法」→ **必须明确提示版权风险，拒绝逐句换词式洗稿**，只提供：
- L2 结构拓扑拆解表（人物功能位、冲突形态、反转序列）；
- L3 戏剧算式卡（信息差/兑换/节拍公式）；
- 换皮三连方案，协助原创全新剧本。

### 仿写项目的证据链

交付新剧本时**必须同附**：《外壳禁用词表》+《算式卡》—— 证明「像」来自机制层而非表达层。四问自检任一不过即回炉。

## 二、内容合规要点（广电 16 号令）

完整 11 条红线与敏感词转译表见 `vendor/short-drama-factory/references/screenplay-compliance-rules.md`，要点：

- 恶行不过 3 集受惩；严禁私刑致命救济；
- 暴力用写意替代（受力震飞/骨裂/倒地），不写直观血腥；
- 穿越/重生机制用科学解释（实验事故/游戏 bug），不走玄学法术；
- 反拜金、公权力威严不可冒犯；
- 灵异/封建迷信/伪乱伦题材 = 题材红线，**不能靠修改修复，建议放弃**。

## 三、违规内容的处理方式

| 发现 | 处理 |
|---|---|
| 🔴 题材涉红线 | 不能修 → 建议放弃 |
| 🟡 场景擦边（虐感过激/暴力过度） | 降表达强度，改暗示不展示 |
| 🟢 个别擦边词 | 直接替换 |

**每次修改后自检**：修改是否引入新违规？冲突升级是否越过暴力美化线？角色关系改动是否产生伪乱伦感？新增设定是否依赖封建迷信？
