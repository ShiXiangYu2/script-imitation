# 08 · 小传级换壳规程（A⁻ 模式）

> v1.1 新增，源自 2026-11-12 首单实战：对标「人物小传+分幕梗概」材料 → 产出全新小传+梗概（不写剧本正文）。产出层级是**立项层**：换好的小传+梗概可直接作为后续 B 模式扩写或人工创作的输入。

## 一、适用判定

- 用户给的对标材料是**小传+梗概**（非剧本正文），且明说「不用扩写正文，只换壳」→ A⁻；
- 用户给剧本但只要新立项方案 → 先走 A 模式拆解（`02-仿写三层抽离法.md`），产出算式卡后同样可用本规程换壳到小传层。

## 二、七步规程

### Step 1 立黑名单（剥壳）
对标材料里逐类拉黑，30~45 项为宜：
1. **人名全列**（包括配角与长辈，一个不漏——换壳稿任何角色名都不得沿用或谐音近似）；
2. **机构名**（家族/公司/门派）；
3. **标志性道具与金额**（原剧的具体数字、信物、取证工具：定损单金额、遗产金额、耳机……）；
4. **金句/口头禅**（「赔钱或赔人」式钩子台词、称呼梗、家训腔）；
5. **开场老梗与剧名点题句**。
格式：每行一个「词|类型」，落盘为 txt 随交付附上。

### Step 2 拆功能位表（留核的对账底稿）
把对标小传里每个角色压成一行：功能位（女主/男主/终极反派/悲剧反派/恶父/纨绔/绿茶/骄纵女配/仁厚长辈/受难母亲/反水者/闺蜜/臂膀/单箭头/明理长辈）+ 一句话功能描述。**功能位拓扑是唯一 1:1 保留的骨架**。

### Step 3 换皮三连
- 换赛道/行业（金融豪门→珠宝世家、医药集团、非遗老字号、电竞……）；
- 换社会关系（表妹→同门师妹；剧组→拍卖行/设计院/战队）；
- 换冲突场景与犯罪/事故载体（追尾→拍卖指控；纵火→燃气管道；车祸→游艇失事；赌场→地下钱庄——载体换了，机制等价）。

### Step 4 原生桥段设计（防撞车的关键，至少 2 条）
从新行业/新职业**推导**出来的原剧情节线，三条常用手法：
1. **道具三重账**：同一道具在全剧承担三种功能（开局是指控物证 → 中段是取证工具 → 终局是求婚信物），一条线贯穿四幕，原剧没有的独有闭环；
2. **命运回环**：开局的事故载体与终局的危机载体互为镜像（母亲当年游艇落水 ↔ 终局反派劫船风暴），形成主题呼应；
3. **手艺反噬**：女主的职业手艺（修复暗记/账目切割/鉴定底账）反过来成为收网铁证——把「高维底牌」具体化到新职业上。

### Step 5 金句等价再造
原剧每条标志性金句，在新稿里给**功能等价、字词零重合**的替身（示例为虚构对标）：
- 「三千万，一个子儿都不能少」→「想赎？先把你自己的名字签上去」；
- 分手绝情句「滚出去」→「带上门，别回头」。
判据：遮住两个名字并排读，情绪功能一致、字面零重叠。**禁止同义近换**（「赔钱或嫁我」这种懒改会被黑名单+四问双卡拦住——黑名单拦不住时要靠四问第 1 条「句式影子」拦）。

### Step 6 重写小传+梗概
- **结构照抄对标的三段式**（核心主角/反派人物/重要配角 + 分幕梗概每幕一段）——结构是公共形式，不属于表皮；
- 每个人物两段左右：第一段处境与创伤（对应原稿创伤机制、载体已换），第二段弧光与终局；
- 梗概按幕写，幕边界与付费墙卡点（15/30/50/70）与原作等价对位；
- 金额、信物、称呼全部按新壳重造（1400 万→1800 万；戒指→胸针改制戒指）；
- 写作时走 `05-台词工艺与去AI味.md` 的痕迹清单，禁段尾升华/说明书腔。

### Step 7 机检 + 交付三件套
```bash
# 黑名单只对正文跑（切掉附录对照表再检）
python scripts/check_banlist.py <正文文件> --banlist <黑名单表>
python scripts/check_ai_patterns.py <正文文件>
```
- 命中黑名单 1 处即回炉改写该句；
- 交付：①换壳稿（md+docx，另存新文件）②附录四件（功能位对照表/换三留一记录/原生桥段记录/四问自检）③黑名单表 txt。

## 三、常见坑（实战记录）

| 坑 | 处置 |
|---|---|
| 机检被附录对照表里的原作名误报 | 检查前按「附录/对照表」标题切分，只检正文 |
| 改写时下意识带出原稿口头禅（如「祖训」这类通用词也被拉黑） | 命中即回炉改写整句，不做同义替换 |
| 换壳只换人名、行业像贴皮 | 用 Step 4 原生桥段倒逼：新桥段必须从新行业推导不出来 = 行业没换到位，重换 |
| 金句再造近义复读 | 四问自检第 1 条 + 黑名单金句段双卡 |
